We've agreed on version 3 of the tsarc archive format; the spec is docs/FORMAT_v3.md. Please implement it in tsarc, including every API, CSV/JSON, stats, expression, resample, verify, info and CLI change the spec lists (nullable columns, chunk statistics and range queries that skip chunks, migrate, add-column). Version 3 becomes the default write format. Version 1 and 2 files must keep reading exactly as before, and writing version 1 or 2 on request must still produce exactly the same bytes as today. Error messages for damaged version 3 files must match the spec word for word. Update the existing tests where the new default legitimately changes their expected output, and add tests for the new behaviour. Standard library only.
