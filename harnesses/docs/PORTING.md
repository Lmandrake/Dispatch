# What ports from Claude Code to Pi and OMP

Generated by `harnesses/gen/make_configs.py` into agent storage
(`<agent-storage>/NewHarness/agents/{pi,omp}-{full,bare}/`) on every launch; `~/.claude` is only read.

| Claude Code piece | Pi | OMP | How |
|---|---|---|---|
| `env.ANTHROPIC_BASE_URL`, `ANTHROPIC_DEFAULT_*_MODEL`, `ANTHROPIC_SMALL_FAST_MODEL` | yes | yes | custom provider `gateway`, `api: anthropic-messages`, models listed from the env; `[1m]` marker becomes a 1M context window |
| `apiKeyHelper` | yes | yes | `apiKey: "!bin/genai-token"` + `authHeader: true` (gateway wants `Authorization: Bearer`; `x-api-key` is refused). `bin/genai-token` caches for `CLAUDE_CODE_API_KEY_HELPER_TTL_MS` like Claude Code |
| `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` | n/a | yes | OMP honours the same switch; launchers export it |
| `~/.claude/CLAUDE.md` | yes | yes | copied to `<agent-dir>/AGENTS.md` (verified: both answer a question from it) |
| `~/.claude/skills/*` (symlinks) | yes | yes | Pi `settings.json` `skills`; OMP `skills.customDirectories` (verified: both list skills) |
| MCP servers in `~/.claude.json` | yes | yes | `<agent-dir>/mcp.json`. an MCP server with many tools connects; one launched through `npx` fails on both: `npx` cannot resolve `chrome-devtools-mcp` (that route is retired) |
| `hooks` (PreToolUse guards, statusline, etc.) | no | partial | Pi has no Claude-format hooks. OMP has TS/JS hooks mirroring `.claude/hooks/pre|post/`, but Claude hooks are settings.json shell commands with Claude Code's JSON contract; not translated. **Consequence: Claude safety-guard hooks do not run under Pi/OMP.** |
| `permissions` allow/deny | no | no | different permission models; both harnesses run tools without Claude Code's allowlist |
| `enabledPlugins` / marketplaces | no | possible | OMP can opt into `claude-plugins` via `enabledProviders`; not enabled (would pull plugin hooks and skills twice) |
| `statusLine`, `theme`, `tui`, `viewMode`, `companyAnnouncements` | no | no | Claude Code UI only |
| auto-memory (`~/.claude/projects/*/memory`) | no | no | Claude Code feature |
| Subagents (`Agent` tool), `run_in_background` | no | partial | Pi has none built in; OMP has a task tool with its own agent definitions |
| Slash commands (`~/.claude/commands`) | no | possible | not translated |

The `bare` profile carries only the model route, so benchmarks compare harness overhead, not
payload size.
